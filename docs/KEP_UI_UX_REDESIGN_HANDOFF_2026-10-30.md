## 1. 프로젝트 목적과 이번 피드백

KEP는 정부기관이나 취업알선기관이 아니다. 공식 G-to-G/EPS 절차를 이해·준비·확인하도록 지원하는 독립적인 민간 서비스다. 합격, 입국, SLC 또는 일자리를 보장하지 않는다. 공식 신청은 정부의 공식 경로로 연결한다.

인도네시아 현지 검토자의 피드백:
- 취지는 흥미롭고 실제 취업 준비생에게 유익할 가능성이 있다.
- 현재 UI는 'AI로 만든 프로토타입'처럼 보이고 자연스러운 제품 정체성이 약하다.
- 정보량이 많아 처음 EPS를 접하는 사용자가 압도된다.
- 모든 안내는 공식 원문 링크 및 사용자가 검증 가능한 출처가 명확해야 한다.
- 비공식 브로커/calo가 여전히 관련 있는 문제다. 사용자는 절차 이해 부족, 어려운 정보, 지속적인 도움 필요 때문에 제3자에게 의존한다.
- 홍보뿐 아니라 교육, 정보 검증, 기능 개발 등을 포함하는 장래 협력 가능성을 열어 두었다.

**해석 주의:** 단일 관계자의 질적 의견이다. 시장 규모, 브로커 이용률, 결제 의사 또는 제휴가 확인된 것은 아니다.

## 2. 제품 방향 — 정보 백과사전에서 '나의 다음 행동'으로

가장 중요한 사용자 질문: **'나는 지금 어느 단계인가? 오늘 무엇을 해야 하는가? 이것이 공식 정보인가?'**

UI 우선순위:
1. 내 현재 상태 / 다음 한 가지 행동
2. 그 행동에 필요한 준비물과 경고
3. 공식 출처, 갱신일, 적용 대상, 아직 확인되지 않은 정보
4. 이전/다음 단계 및 선택적 상세 내용
5. 부가 도구, 상세 자료, 커뮤니티, 백업 및 고급 기능

초보자에게 전체 기능과 수십 가지 정보를 한꺼번에 표시하지 않는다. 단, 중요 안전 경고(사기/비공식 수수료/접수 기간 마감)는 감추지 않는다.

## 3. 참고 서비스 및 가져올 요소

### A. Boundless (이민 신청 안내) — 개인화된 업무 흐름
- https://www.boundless.com/boundless-faqs
- 참조: 짧은 적격성 질문, 가이드형 질문, 개인별 문서 체크리스트, 증빙 제출·검토 흐름.
- KEP에 적용: 초보자 현재 단계 선택 -> 개인별 다음 작업 카드 -> 서류·출처 확인.
- 복제 금지: 미국 법률 서비스 표현, 변호사 리뷰/대리 접수 같은 기능을 KEP가 제공하는 것처럼 표시하지 않는다.

### B. GOV.UK Design System — 절차·양식·접근성·신뢰성
- https://design-system.service.gov.uk/
- https://design-system.service.gov.uk/patterns/step-by-step-navigation/
- 참조: 업무 순서, 명료한 문장, 폼 에러·도움말, 키보드와 스크린리더, 정부 안내와 원문 링크.
- 주의: GOV.UK 자체도 step-by-step은 긴 여정을 안내하는 *내비게이션*이며, 서비스 안에서 실제 진행 상황을 관리할 때는 task list 패턴을 구분하도록 설명한다.
- KEP에 적용: 공통 task list, 각 단계에 공식기관·출처·최종 확인 날짜·사용자 행동을 나란히 표시.

### C. Duolingo — 처음 방문·모바일 사용성·작은 인터랙션 완성도
- https://blog.duolingo.com/core-tabs-redesign/
- 참조: 처음 시작할 때 하나씩 선택, 일관적인 탭과 명료한 계층, 작은 UI의 마감 및 실제 기기 QA.
- KEP는 정부 취업 절차의 신뢰성이 우선이므로 과도한 게임화, 캐릭터, 불필요한 축하 애니메이션 사용 금지.

### D. 현지 기능 벤치마크
- SISKOP2MI/KP2MI 공식 채널: 실제 신청 진입점 및 최신 공고/적법성의 원천.
- EPSTOPIK.ID 등 학습 서비스: 시험 준비 하나에 집중하는 구조, 기능 경쟁 범위 확인.
- 기능이나 브랜딩을 무단 복제하지 않고 사용자 작업과 정보 구조만 참고.

**조합은 고정 퍼센트가 아니라 원칙:** Boundless식 개인별 다음 행동 + GOV.UK식 공식·명확한 절차 + Duolingo식 간결한 모바일 첫 사용.

## 4. 화면별 목표 설계

### 4.1 첫 방문/상태 선택
- 우선 3개: 아직 등록 전, 온라인 등록 후 시험 전, 시험 응시 후.
- 후기 단계(선발, 명부, SLC, 입국 이후)는 펼침 메뉴로 노출.
- 애매하면 '더 정확히 선택' 및 '완전히 처음부터' 제공.
- 단계 선택 이후: 다음 행동, 해당 단계 위험 경고, 필요 문서, 출처를 보여줌.
- 선택한 단계가 실제 공식 상태임을 확인한 것처럼 표현하지 않는다.

### 4.2 로그인/재방문 홈
- 최상단: KEP 브랜드, 현재 경로(Indonesia -> E-9 -> Manufacturing), 비정부 서비스 표시.
- 메인 카드: '현재 단계 / 다음 행동' 하나; 가능하면 한 화면에서 다음 버튼까지.
- 접수 마감/기간 미확인/공식 원문 변경 사항은 시각적으로 분리.
- 보조: Dokumen, Biaya, Bantuan, Tahapan; 고급 설정·백업은 접어 둠.
- 휴대폰 320/360/375/390/430px, 태블릿, 데스크톱에서 일관되게 사용.

### 4.3 단계별 안내/문서
- 단계 제목, 목적, 지금 할 행동, 서류, 비용, 공식 기관, 공식 원문 링크, '마지막 확인', 확실성.
- 절차가 개인 상황 또는 공고 회차에 따라 달라질 때는 조건을 명시.
- 원문이 불확실하거나 업데이트 검증이 필요할 때 추측 답변 금지; 사람에게 문의할 공식 채널 제시.
- 장문의 설명은 펼침, 핵심 작업은 기본 화면에 유지.

### 4.4 질문/답변
- 확실하게 검증된 답과 예시를 분리.
- 출처 없는 '확답', 법률·이민 절차 단정, 허위의 진행 상태 표시 금지.
- 결과에는 출처, 적용 범위, 갱신/검증 상태, 공식 담당 기관 문의 연결.

### 4.5 모달/팝업
- 모든 닫기(X)는 모달 헤더에 고정되며 내부 콘텐츠 스크롤 시에도 사라지지 않음.
- 모바일 화면 높이 제한, 키보드/안전 영역 고려, 닫기/뒤로가기/포커스 복귀.
- 실제 사용성 테스트 대상으로 포함.

## 5. 디자인 시스템 고정값 (초안 — 시각 검증 후 LOCK)
- 톤: 차분한 그린·오프화이트·회색, 과한 네온/그라데이션/색상 남발 지양.
- 시각 계층: 페이지 제목 > 현재 행동 > 핵심 상태 > 세부 설명 > 보조 메뉴.
- 8px 계열 간격, 최소 약 44px 터치 표적, 충분한 대비, 일관된 라운드/보더.
- 카드 한 화면에 과도한 중첩 금지. 무의미한 배지·퍼센트·진행률 표현 금지.
- 아이콘은 의미를 명확히 전달할 때에만 사용.
- 반응형: 가로 스크롤, 잘린 CTA, 하단 내비게이션과 콘텐츠 겹침 없음.
- 한글 개발 노트와 별개로 사용자 UI는 자연스러운 인도네시아어 원어민 검토 필요.
- 인도네시아 대상 UI 및 데이터의 현행성과 번역을 분리 검수.

## 8. 완성 판정 기준
- 핵심 사용자 여정: 처음 방문 -> 자신의 단계 선택 -> 다음 행동 확인 -> 공식 원문 접근을 혼동 없이 완료.
- 320px 이상 모바일에서 가로 넘침 0, 닫기 불가 모달 0, CTA 가림 0.
- 기존 기능·경로·저장된 진행 상태 보존.
- 공식 출처가 불확실할 때 단정·추측 0.
- 자동 테스트 신설 2개 포함 전체 중요 회귀 시나리오 PASS; 불가 시 사유 및 영향 명시.
- 독립적인 현지 사용자 평가와 시각 검수 완료.
- 사용자가 디자인을 승인하기 전 운영 반영 금지.

## 9. Work 대 Site/웹 브라우저 역할
