# KEP M35 — 2026 일반 제조업 최종 구직등록 제출서류 증거 형식 검증

**기준일:** 2026-10-17 KST/WIB

**검증 대상:** Indonesia → E-9 → General Manufacturing → 2026 → **post-Skill-Test 최종 온라인 구직등록**

**기본 결론:** 해당 모집 주기의 실제 최종 온라인 구직등록 원문/첨부 파일은 아직 확인·서명되지 않았음. **`job_docs=HOLD`, 공개 베타=HOLD**.

## 1. 해결하려는 실제 문제

이전 M34 검토 패킷은 공식 출처 변경 경고 12건, 7개 제조업 관련 공고, 별도 최종 구직등록 서류 게이트 1건과 출시 게이트 10건을 담당자에게 넘기는 작업 지시서였습니다. 하지만 서류를 승인하려는 사람이 **어떤 모집연도·업종·원문 PDF의 어느 페이지**를 근거로 제출파일의 필수/선택 상태를 정했는지 검사할 입력 계약이 분명하지 않았습니다.

M35는 실제 승인 권한을 가정하지 않는 **독립적인 구조 검증기**를 추가했습니다. 공식 사이트를 새로 다운로드하고 원본 진위를 증명하는 도구가 아니라, 나중에 사람이 증거를 제출했을 때 아래 필수 연결이 누락되면 절대 출시자료로 사용하지 못하도록 하는 도구입니다.

## 2. 새 구조 검증기

`scripts/check_m35_final_job_docs_original.py` 및 `research/source_reviews/indonesia_m35_final_job_docs_evidence_template_2026-10-17.json`

공식 원문 증거 제출 시 요구되는 것:

| 항목 | 요구 근거 |
|---|---|
| 모집 대상 | 2026년 인도네시아 E-9 **General Manufacturing**, Skill Test 이후 온라인 구직신청 |
| 공고 URL | 정확한 KP2MI 공식 HTTPS `/gtog-detail/korea/` 경로, 제목·URL에서 2026/제조업/온라인 신청 분야 확인 |
| 공고 날짜 | 실제 2026-09-17 이후 발표 및 검토 날짜 이전 |
| 공고 원문 | SHA-256 64자리, 관련 조항·문단 위치 |
| 첨부 파일 | 각 공식 KP2MI PDF의 원문 링크, 바이트 SHA-256, 페이지 수 |
| 제출서류 각 항목 | 인도네시아어 이름, 명시적인 **필수 또는 선택** 구분, 원문 PDF·페이지·근거 인용, 중복 없는 ID |
| 담당자 | 가명·테스트 이름이 아닌 실제 내부 검토자, 인도네시아 현지 날짜로 일치하는 시간대 포함 시각, 적용 분야·연도 판단의 구체적 사유 |

**중요한 제한:** 위 필드가 모두 형식적으로 채워져도 그 값이 실제 공식 원문과 같다는 증거는 아닙니다. 원본 PDF를 별도로 다운로드/시각 검토한 기록, 원문 페이지 및 담당자의 진짜 확인·승인, 지원자에게 공개될 규칙의 독립 회귀검사와 배포 검증이 여전히 필요합니다. 본 검증기의 반환값은 **서류 증거의 구조적 완성도만** 뜻하며 승인·서류 규칙 승격·베타 OPEN으로 연결되지 않습니다.

## 3. 실행 결과

- **27개 fail-closed 위험 시나리오 PASS**: 2025년 서류, 어업, 최초 시험접수, 잘못된 공식 호스트, 첨부 PDF 누락, PDF 페이지 번호 이탈, 모집연도·공고일 불일치, 필수서류 임의 삽입, 담당자 가명, 서명·배포·베타 임의 승인 등.
- 추가로 **검증용 가상 완성 사례의 구조 PASS**를 먼저 확인한 뒤 부정 사례를 검증함. 가상 사례는 오직 테스트 메모리에만 있고 GitHub/시트에 사람 승인으로 기록되지 않음.
- 실제 M34 20개 검토 대기 작업, M33 **2026년 최종 제출서류 독립 출시 차단**, 지원자용 문서팩 `items=[]`를 함께 검증.
- 제출용 JSON 템플릿의 원문/담당자/제출파일 항목은 모두 **null 또는 빈 배열**, 상태는 `official_2026_final_notice_not_established`; 검증 완료·베타 승인 필드는 모두 `false` 또는 `hold`.

## 4. 실제 승인자가 해야 하는 일

1. [KP2MI G-to-G Korea 공고](https://kp2mi.go.id/gtog-korea/pengumuman)에서 2026 UBT Umum **제조업 최종합격 후 온라인 구직등록** 공고 및 공식 첨부를 확보합니다.
2. 공고가 실제 발행되면 원문과 PDF 페이지에서 제출서류의 종류·필수 여부·대상자·기한·공고 효력을 담당자가 읽고 구분합니다. 과거 2025 제조업, 2026 어업·Root Industry·특별시험, 최초 EPS-TOPIK 시험접수, 2026 Skill Test 선택적 증빙은 대체할 수 없습니다.
3. 담당자 실명·검토시각·페이지 근거를 기록하더라도 본 검증기만으로 출시가 승인되는 것은 아닙니다. 새 공식 원문의 **실제 바이트/페이지 내용 확인**, 별도 문서팩 규칙 변경과 독립 테스트, 책임자 서명, 승인된 배포의 동일 SHA 9/9 및 HTTPS 6/6, 별도 운영자의 베타 OPEN 결정이 필요합니다.
