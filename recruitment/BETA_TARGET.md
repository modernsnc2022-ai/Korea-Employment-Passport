# Indonesia beta cohort

Target A: 30 people currently in G-to-G Korea process
- preparing EPS-TOPIK
- registered/tested
- skill-test stage
- job roster waiting
- SLC received
- visa/departure stage

Target B: 20 Indonesians already working in Korea on E-9

Primary success metric:
Broker Replacement Rate = broker tasks no longer needed / all broker tasks encountered.

PASS condition for supported route:
- 100% of necessary private-broker tasks replaced
- official-authority steps clearly routed
- licensed-professional steps, if any, completed without private broker hunting

## Beta ID and privacy rule

Use only the pseudonymous codes `KEP-0001` through `KEP-0050` in this repository.
- `KEP-0001`–`KEP-0030`: target active G-to-G applicants.
- `KEP-0031`–`KEP-0050`: target Indonesian E-9 workers in Korea / retrospective reviewers.
- The app accepts the code locally and includes it in sanitized beta feedback so reports can be matched to the tracker.
- Do **not** commit participant names, nicknames/handles, phone numbers, email addresses, passport/KTP/ARC numbers, exact home addresses, or private intermediary names to this public repository.
- If direct contact details are needed for recruitment/follow-up, keep them in a separate access-controlled system keyed only by `tester_id`.
- Free-text tracker notes must remain non-identifying.
